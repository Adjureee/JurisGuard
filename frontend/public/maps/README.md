# Offline administrative boundaries

`philippines-cities.geojson` is the simplified Philippines ADM3 (city/municipality)
boundary layer distributed by geoBoundaries gbOpen. Downloaded 2026-11-04.

Source metadata: https://www.geoboundaries.org/api/current/gbOpen/PHL/ADM3/
Source organisations: NAMRIA, PSA, OCHA Philippines.
License: Creative Commons Attribution 3.0 Intergovernmental Organisations
(CC BY 3.0 IGO). https://creativecommons.org/licenses/by/3.0/igo/

This is a generalized administrative reference, not barangay boundaries, street
tiles, or verified residential coordinates. The app serves this file locally;
runtime viewing does not require an external map service.

## Offline province lookup

`frontend/src/components/dashboard/cityProvinceIndex.json` associates this exact
ADM3 edition's shape IDs with geographic province labels for name disambiguation.
It is generated by `scripts/build_city_province_index.py` from the pinned
[geoBoundaries PHL ADM2 metadata](https://www.geoboundaries.org/api/current/gbOpen/PHL/ADM2/)
(NAMRIA / PSA / OCHA Philippines, CC BY 3.0 IGO). The generated file records the
source URLs and SHA-256 checksums. The development builder requires Shapely;
application use is entirely offline and needs no Python geometry dependency.

Only a unique province covering at least 95% of a municipality polygon's area is
accepted. All 1,647 installed city/municipality shapes currently meet that check.
These are geographic reference labels, not a claim of provincial jurisdiction
over independent cities. Source-era Compostela Valley is matched to the current
Davao de Oro name. No client data is read by the builder or sent to any service.
