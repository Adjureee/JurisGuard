# Offline administrative boundaries

`philippines-cities.geojson` is the simplified Philippines ADM3 (city/municipality)
boundary layer distributed by geoBoundaries gbOpen. Downloaded 2026-11-04.

Source metadata: https://www.geoboundaries.org/api/current/gbOpen/PHL/ADM3/
Source organisations: NAMRIA, PSA, OCHA Philippines.
License: Creative Commons Attribution 3.0 Intergovernmental Organisations
(CC BY 3.0 IGO). https://creativecommons.org/licenses/by/3.0/igo/

This is a generalized administrative reference, not barangay boundaries, street
tiles, or verified residential coordinates. The app serves this file locally;
runtime viewing does not require an external map service.
